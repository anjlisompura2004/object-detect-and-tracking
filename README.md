# Object-detect-and-tracking project
<h1 align="center">🚀 Object Detection and Tracking System</h1>

<p align="center">
A real-time Object Detection and Tracking system using OpenCV, YOLO, and SORT algorithm.
</p>

<hr>

<h2>📌 Project Overview</h2>
<p>
This project implements a real-time object detection and tracking system using computer vision techniques.
It captures video input from a webcam or video file, detects objects using a pre-trained YOLO model,
and tracks them across frames using the SORT (Simple Online Realtime Tracking) algorithm.
</p>

<hr>

<h2>⚙️ Features</h2>
<ul>
  <li>🎥 Real-time video processing using OpenCV</li>
  <li>🧠 Object detection using YOLO (You Only Look Once)</li>
  <li>📦 Bounding box visualization with labels</li>
  <li>🔢 Unique ID assignment for each tracked object</li>
  <li>📍 Object tracking using SORT algorithm</li>
  <li>⚡ Fast and efficient performance</li>
</ul>

<hr>

<h2>🛠️ Technologies Used</h2>
<ul>
  <li>Python</li>
  <li>OpenCV</li>
  <li>YOLO (Pre-trained Model)</li>
  <li>NumPy</li>
  <li>SORT Algorithm</li>
</ul>

<hr>

<h2>📂 Project Workflow</h2>
<ol>
  <li>Capture video input (webcam/video file)</li>
  <li>Process each frame using OpenCV</li>
  <li>Apply YOLO model to detect objects</li>
  <li>Draw bounding boxes around detected objects</li>
  <li>Pass detections to SORT tracker</li>
  <li>Assign tracking IDs to each object</li>
  <li>Display output in real-time</li>
</ol>

<hr>

<h2>📸 Output</h2>
<p>
The system displays real-time video with:
</p>
<ul>
  <li>✔️ Bounding boxes</li>
  <li>✔️ Object labels</li>
  <li>✔️ Tracking IDs</li>
</ul>
